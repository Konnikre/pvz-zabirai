ПВЗ «Забирай» - пункт выдачи заказов, учебная практика (Python 3 + SQLite + Tkinter)

Запуск:
  1. python seed.py      - создать БД pvz.db с тестовыми данными
  2. python main.py      - запустить приложение (окно входа)

Пользователи:  admin / admin123   manager / manager123   report / report123
  admin   - всё, включая сотрудников и резервную копию
  manager - приём, изменение, выдача и возврат заказов
  report  - только просмотр и отчёты

Как работает пункт выдачи:
  Приём заказа  -> статус «На хранении», срок хранения 7 дней (repository.STORAGE_DAYS)
  Выдача        -> клиент называет 4-значный код получения, принимается оплата (если есть)
  Возврат       -> заказ с истекшим сроком уходит обратно отправителю
  Красным в таблице выделены заказы, у которых осталось 2 дня хранения и меньше

Файлы:
  create_db.sql  - DDL: таблицы, индексы, представления, триггеры
  db.py, models.py, repository.py  - доступ к данным (sqlite3, dataclass)
  queries.py     - 7 SQL-запросов (python queries.py - вывод в консоль)
  reports.py     - отчёты, экспорт в CSV и HTML (папка reports/)
  auth.py, validators.py, gui.py, main.py - вход, проверки, интерфейс
  backup.py, restore.py - резервное копирование и восстановление
  config.ini     - путь к файлу БД
  setup.cfg      - настройки flake8 и pylint (длина строки 100, сложность не более 10)
  Название пункта выдачи меняется одной строкой: APP_NAME в db.py

Проверка кода (этап 4):
  python -m flake8 .
  python -m pylint *.py
  python -m radon cc -s -a .
  run_tests.bat          - автотесты и покрытие
